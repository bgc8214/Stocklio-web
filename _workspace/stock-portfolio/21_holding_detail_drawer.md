# 21. 종목 상세 드로어 (보유 종목 · 종목별)

작성일: 2026-08-15 · 대상: `보유 종목` 탭(`src/react/views/HoldingsView.jsx`, `styles/holdings.css`)

## 배경 / 필요성 판단

레퍼런스(타 앱)의 종목 상세 페이지를 보고 "종목을 누르면 상세가 있으면 어떨까" 요청. 실제 필요성부터 검토:

- **계좌별 뷰**: 종목×계좌를 한 줄씩 → 같은 종목을 여러 계좌에 보유하면 목록에 **흩어짐**.
- **종목별 뷰**: 티커로 합산한 카드 → 합계는 보이나 **계좌별 분해가 사라지고**, 카드가 클릭 불가.

즉 "한 종목을 계좌별로 분해해서 보는 화면"이 **어디에도 없었다.** 멀티계좌 앱이라 이게 레퍼런스의 핵심 가치와 정확히 일치 → **필요하다고 판단.** 진입점은 사용자 직관대로 **종목별 카드 탭**.

## 무엇을 넣고 뺐나 (정직하게)

레퍼런스 항목 중:
- **못 넣음**: 실현손익, 종목별 매매 이력 — 우리는 매수/매도 체결·로트를 저장하지 않음(cashFlows는 계좌 단위 입출금/배당뿐). 억지로 넣으면 가짜 데이터라 **제외**하고 안내 문구로 명시.
- **넣음**: 평가금액·원금·총손익(+%)·일 영향·평단·수량·비중 요약 / **계좌별 보유 분해**(핵심) / 이 종목 **예상 연 배당**(티커별 TTM 재사용).
- 스파크라인은 1차에서 보류(사용자 합의).

## 구현

- 진입: 풀 페이지 대신 **드로어**(`.side-drawer` 재사용, 라우터 없는 SPA에 적합, 모바일 풀시트). 종목별 카드를 `<button>`으로 바꿔 탭 시 `HoldingDetailDrawer` 오픈. 카드에 "계좌별 ›" 어포던스.
- `HoldingDetailDrawer`: 티커로 보유 필터 → 집계(수량·평가·원금·손익·일영향·비중), 계좌별 행(계좌·투자자·수량·평단·평가금액·손익%), 예상 배당은 `getDividendInfo(ticker)` 온오픈 조회.
- hallmark: 신규 테마 없이 기존 토큰만, `tabular-nums`, `signClass`(양수 상승·음수 하락·0 중립), hover/focus-visible, 라이트/다크 대응.

## 검증

- 샘플은 종목당 1계좌뿐이라 계좌별 1행으로 표시됨(다계좌 분해는 계좌별 뷰와 동일한 filter+map 이라 N행 안전).
