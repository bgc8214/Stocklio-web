# 19. 계좌 탭 예수금 입력·수정 UX 개선

작성일: 2026-08-08 · 대상: `계좌` 탭 (`src/react/views/AccountsView.jsx`, `styles/accounts.css`)

## 배경

계좌 탭에서 예수금을 입력·수정하는 흐름이 UX적으로 이해하기 어렵고 불편하다는 피드백. 실제 코드와 렌더 화면을 함께 분석해 원인을 정리하고 개선했다.

## 개선 전 문제 분석

1. **입력·수정 경로가 3곳에 분산 + 중복**
   - ① 계좌 카드 클릭 → 아코디언 펼침 → 통화/예수금/저장
   - ② "미분류 예수금 배분" 박스(조건부)
   - ③ 하단 "예수금 변경 기록" 패널에서 인라인 수정/삭제(계좌·통화 재지정까지 가능)
   - 같은 예수금을 ①과 ③ 두 곳에서 편집 → 어디가 정본인지 불명확.
2. **"예수금 변경 기록"이 이름과 기능 불일치** — 이력처럼 보이지만 실제로는 *현재 잔액 목록 + 편집기*. ③에서 계좌/통화를 바꾸면 `investor+account+currency` 유니크 키와 어긋나 **같은 계좌에 예수금 레코드가 중복 생성 → 이중 집계** 가능(데이터 무결성 위험).
3. **입력 진입점 발견성 낮음** — 헤더는 "예수금을 선택"이라 하지만 실제로는 계좌 카드 전체를 클릭해야 폼이 열림. 클릭 대상과 목적의 연결이 약함.
4. **표시 금액의 이중성** — 카드 총액은 KRW 환산인데 입력칸은 원통화. 펼칠 때 KRW→통화 역산·반올림으로 값이 미세하게 달라짐.
5. **통화 선택 중복** — 계좌에 baseCurrency가 있는데 예수금에서 통화를 또 고름.
6. **드래프트 잔존 + Enter 미지원** — 저장 안 하고 접었다 펴면 옛 값이 남음. 저장 버튼이 form submit이 아니라 Enter로 저장 불가.
7. **계좌 생성과 예수금 입력 분리** — 계좌 추가 후 다시 찾아 펼쳐 입력. "예수금 미입력 N개" 경고 카드는 눌러도 아무 동선 없음.
8. **"미분류 예수금 배분"이 맥락 없이 등장** — 가져오기 산물인데 설명 없음.

## 개선 내용

원칙: **"예수금은 계좌의 속성" — 편집 진입점을 계좌 카드 한 곳으로 통일.**

| # | 개선 | 대응 문제 |
|---|---|---|
| 1 | 하단 패널을 **읽기 전용 "예수금 현황"**으로 전환(수정/삭제·계좌 재지정 제거). 계좌·출처·기준일·원통화·KRW 환산 표시 | 1, 2 |
| 2 | 계좌 카드에 **예수금 값 + ✎편집 버튼 상시 노출**. 클릭 시 그 자리 인라인 편집기(계좌 펼침과 분리) | 1, 3 |
| 3 | 편집기 라벨에 **통화 명시("예수금 (USD)")** + **KRW 환산·환율 힌트** 표기 | 4, 5 |
| 4 | 편집기를 `<form>`으로 만들어 **Enter 저장** 지원, 열 때 **항상 최신 저장값으로 초기화**, 저장 후 카드에 **"저장됨 ✓"** 인라인 확정 | 6 |
| 5 | **계좌 추가/수정 폼에 "예수금(선택)" 필드** 추가 → 계좌 생성 시 예수금 함께 upsert | 7 |
| 6 | **"예수금 미입력 N개" 카드를 필터 버튼**으로 전환 → 클릭 시 미입력 계좌만 표시(토글) | 7 |
| 7 | 미분류 예수금 배분 박스에 **1줄 설명** 추가 | 8 |

### 데이터 무결성

- 예수금 편집·계좌폼 upsert 모두 `investor + account + currency` 기준 **단일 레코드 upsert**로 통일. 하단 패널의 계좌 재지정 편집을 제거해 **중복 레코드 생성 경로를 차단**.
- 저장 후 `cashBalances` 길이 불변(중복 없음) 검증 완료.

## 변경 파일

- `src/react/views/AccountsView.jsx` — 카드 인라인 예수금 표시/편집기, 미입력 필터, 계좌폼 예수금 필드, 하단 read-only `CashStatusList`로 교체(기존 편집형 `CashBalanceList` 제거), 드래프트/포커스/저장 확정 로직.
- `styles/accounts.css` — `.account-cash-quick`, `.account-cash-editor`, `.cash-krw-hint`, `.allocation-hint`, `.cash-balance-krw`, 미입력 카드 버튼/`is-active`, 모바일 단일 컬럼 반응형.

## 검증

- 기능: 카드 ✎편집 → 금액 변경 → Enter 저장 → 반영, `cashBalances` 중복 없음(3→3), 미입력 필터 토글, 콘솔 에러 0.
- 시각: 데스크톱/모바일 × 라이트/다크 4조합 스크린샷 확인.
- `npm run check` 통과.

## 남은 아이디어(후속)

- 진짜 예수금 *변경 이력*(이전값→새값·시각) 저장 및 별도 타임라인 노출.
- 계좌별 다중 통화 예수금이 필요할 경우의 명시적 모델(현재는 계좌당 baseCurrency 1건 전제).
