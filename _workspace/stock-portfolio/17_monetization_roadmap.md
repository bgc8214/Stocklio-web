# 수익화 로드맵: 개인 도구에서 돈 받는 제품까지

작성일: 2026-07-17. 15번(개선 방향성)·16번(코드 레벨 리뷰)의 후속. 이 문서는 "무엇을 만들어야 팔 수 있는가, 누구에게 어떻게 알릴 것인가, 지금 무엇이 부족한가"를 다룬다.

## 결론

Stocklio가 팔릴 수 있는 이유는 명확하다: **여러 증권사·여러 가족 구성원·연금/ISA/일반계좌에 흩어진 자산을 한 화면에서, 매일 자동으로, 스프레드시트 없이 기록해주는 도구**는 국내에서 의외로 비어 있는 자리다. 증권사 앱은 자기 계좌만 보여주고, 자산관리 앱은 "조회"는 해줘도 "기록의 소유권"(내 데이터를 내가 내보내고 되돌리는 것)과 "가족 단위 관리"에는 약하다.

수익 모델은 **프리미엄 구독(freemium SaaS)** 단일안을 권한다. 광고는 신뢰를 파는 금융 기록 도구와 상극이고, 데이터 판매는 논외이며, 일회성 판매는 서버 비용 구조와 안 맞는다.

가장 중요한 전제: **투자 조언을 팔지 않는다.** 이것은 CLAUDE.md의 제약이자 동시에 법적 방어선이다. "기록·계산·시각화 도구"로 포지셔닝하는 한 유사투자자문업 이슈에서 멀리 떨어져 있을 수 있다. 종목 추천·매매 신호·수익 보장을 파는 순간 규제 대상이 되고 제품의 신뢰 포지션도 무너진다. 수익화 아이디어를 평가할 때 이 선을 넘는 것은 전부 기각한다.

## 1. 타깃과 포지셔닝

### 핵심 타깃 (초기 1,000명을 데려올 사람)

1. **가족 자산 총무** — 본인+배우자+자녀 계좌를 엑셀/Numbers로 관리하던 사람. Stocklio의 investor/account 모델이 정확히 이 사람을 위해 설계되어 있다. 기존 자산관리 앱은 "내 계좌 연동"만 되지 "가족 포트폴리오"가 안 된다.
2. **연금 투자자** — 연금저축·IRP·ISA를 여러 금융사에 나눠 굴리는 사람. 계좌 유형(accountType) 구분과 계좌별 성과가 이미 있다.
3. **미국주식+국내주식 혼합 투자자** — 환율까지 얹어서 성과를 계산하는 게 스프레드시트에서 제일 고통스러운 지점. KRW/USD 이중 통화와 환율 효과 분리(15번 문서 축 2)가 차별점이 된다.

### 포지셔닝 문장

"증권사 5곳에 흩어진 우리 집 투자, 매일 아침 자동으로 기록됩니다. 추천도 광고도 없이, 기록만 정직하게."

- vs 증권사 앱: 전 계좌 통합 + 가족 단위
- vs 오픈뱅킹 기반 자산관리 앱: 계좌 연동 강요 없음(수동 입력의 프라이버시), 기록 소유권(전체 내보내기/백업), 광고·상품 추천 없음
- vs 스프레드시트: 자동 시세/환율/스냅샷, 성과 계산 정확성(TWR/MWR), 모바일

"조회는 그들이 잘한다. 우리는 **기록과 역사**를 판다"가 한 줄 요약이다.

## 2. 요금제 설계

| | Free | Plus (월 4,900원 / 연 49,000원 안) |
|---|---|---|
| 투자자 수 | 1명 | 무제한 (가족) |
| 계좌 수 | 3개 | 무제한 |
| 보유 종목 | 20개 | 무제한 |
| 일일 자동 스냅샷 | O (핵심 가치는 무료로 체험) | O |
| 스냅샷 히스토리 | 최근 1년 | 무제한 + 소급 backfill |
| 성과 분석 | 기본 수익률 | TWR/MWR, 환율 효과 분리, 계좌 기여도 |
| 알림 | — | Telegram/이메일 일일 요약, 실패 알림 |
| 내보내기 | JSON 백업 | + XLSX/CSV, 세금 신고용 기록 내보내기 |
| 버전 되돌리기 | — | 세대 백업 N개 |
| 시뮬레이터 | 프리셋만 | 커스텀 시나리오 |

설계 원칙:

- **무료 티어가 혼자 쓰기에 진짜로 충분해야 한다.** 금융 기록 도구는 신뢰가 전부라 "무료로 낚고 불구로 만드는" 전략은 역효과. 무료 사용자의 입소문이 마케팅의 절반이다.
- **과금 축은 "가족·역사·정밀함"** — 인원 수(가족), 히스토리 길이(역사), 고급 성과 분석(정밀함). 셋 다 서버 비용과 대략 비례해서 정직한 과금이다.
- 연간 결제 2개월 할인으로 이탈 방지. 초기에는 "창립 멤버 평생 반값" 같은 얼리버드로 첫 100명의 결제 의사를 검증한다.
- 가격 검증: 출시 전 대기 리스트에 가격 설문(Van Westendorp 4문항)을 끼워 4,900원 가설을 확인한다. 국내 구독 심리 저항선(5,000원)을 넘지 않는 게 중요하다.

## 3. 결제받기 전에 반드시 만들어야 할 것 (제품 갭)

돈을 받는 순간 "취미 프로젝트의 관대함"이 사라진다. 순서대로:

### 3-1. 신뢰 인프라 (결제의 전제조건) — 15·16번 문서와 직결

- **다기기 동시성 안전** (15번 축 3, 16번 A-1): 돈 낸 사용자의 데이터가 폰-PC 사이에서 증발하면 환불이 아니라 소송감이다. revision 잠금 + 세대 백업이 유료화의 기술적 전제다.
- **자동화 신뢰** (16번 A-2, D-1): "매일 자동 기록"을 팔면서 스냅샷이 구멍나면 핵심 약속 위반. 실패 알림 + backfill까지가 상품이다.
- **보안 기본기** (16번 B 전체): 결제 사용자를 받기 전에 정적 서빙 allowlist, CSP, XSS lint는 끝나 있어야 한다.

### 3-2. 계정·결제 시스템

- 결제: **토스페이먼츠 또는 포트원(아임포트)** 정기결제 연동. Stripe는 국내 원화 정기결제에 제약이 있어 국내 PG가 현실적. Vercel 함수로 웹훅 수신, Supabase에 `subscriptions` 테이블.
- 구독 상태 → 기능 게이트: 도메인에 `getEntitlements(subscription)` 순수 함수 하나로 중앙화. 뷰마다 if문을 흩뿌리지 않는다.
- 결제 실패/만료 유예(grace period) 7일, 만료 시 **데이터는 절대 삭제하지 않고 읽기+내보내기는 영구 허용** — "데이터 인질극 안 함"을 명문화하면 그 자체가 신뢰 마케팅이 된다.

### 3-3. 법·컴플라이언스

- **이용약관·개인정보처리방침** — 금융 데이터를 다루므로 수집 항목/보관 기간/암호화를 명시. 개인정보보호법상 안전성 확보조치(전송·저장 암호화, 접근 통제) 점검.
- **통신판매업 신고** — 유료 구독 판매 시 필요.
- **"투자 조언 아님" 고지** — 모든 성과/시뮬레이터 화면 하단에 "본 서비스는 기록·계산 도구이며 투자 권유·자문이 아닙니다" 고정. 유사투자자문업 경계에서 확실히 떨어져 있음을 화면 단위로 증명.
- 데이터 삭제권: 회원 탈퇴 시 완전 삭제 플로우와 확인 메일.

### 3-4. 온보딩 (현재 가장 큰 제품 갭)

- 현재 신규 사용자는 빈 화면 또는 샘플 데이터에서 시작한다. 결제 전환은 온보딩에서 결판난다:
  1. 가입 직후 "첫 종목 추가" 가이드 플로우 (티커 검색 → 수량/평단 입력 → 즉시 대시보드 갱신의 아하 모먼트)
  2. 증권사 잔고 화면을 보고 따라 입력하는 체크리스트형 가이드 (증권사별 "어디서 평단을 찾나요" 스크린샷 문서 — 이게 SEO 콘텐츠도 된다, 5절 참조)
  3. 샘플 데이터 → 내 데이터 전환 버튼
- **모바일 완성도**: 매일 아침 확인하는 도구라 실사용은 폰이다. PWA 설치(홈 화면 추가) + 푸시 알림까지가 온보딩의 일부.

### 3-5. 이탈을 막는 유지 장치

- 일일 다이제스트 알림(이미 notification-core가 있음)을 무료에도 주 1회 제공 — 앱을 다시 열게 하는 유일한 훅.
- 월간 리포트 이메일: "이번 달 순입금 X, 자산 증감 Y" — 조언 없이 사실만. 열어볼 이유가 매달 생긴다.

## 4. 단계별 로드맵

### Phase 0 — 검증 (지금 ~ 1개월): 돈 쓰기 전에 수요 확인

- 랜딩 페이지(이미 `landing.html` 있음)에 **대기 리스트 + 가격 설문** 부착
- 본인+지인 5~10가족에게 베타 배포, 주간 사용 데이터 관찰 (어느 탭을 실제로 쓰는가 — 15번 축 5의 Craft.js 결단 근거도 여기서 나온다)
- 목표 지표: 대기 리스트 200명, 베타 주간 재방문율 50%. 미달이면 포지셔닝을 다시 잡고 나서 개발한다.

### Phase 1 — 유료화 준비 (1~3개월): 3절의 갭 메우기

- 신뢰 인프라(3-1) → 결제(3-2) → 법무(3-3) → 온보딩(3-4) 순서
- 16번 문서 우선순위 1~4와 15번 문서 "즉시" 단계가 이 Phase의 기술 백로그
- 얼리버드 100명 결제로 종료

### Phase 2 — 공개 출시와 초기 성장 (3~6개월)

- 5절 마케팅 본격 가동, 무료 가입 → 유료 전환 퍼널 계측(전환율 목표 3~5%)
- Plus 차별 기능 완성: TWR/MWR(15번 축 2), 세대 백업, 세금 기록 내보내기
- MAU 2,000 / 유료 100명(월 매출 ~50만원, 서버비 손익분기) 목표

### Phase 3 — 확장 (6~12개월)

- 거래 원장(15번 축 1) 기반 기능: 실현손익 리포트, 배당 캘린더·연간 배당 리포트 — 유료 전환의 최강 훅이 될 가능성이 높다 (배당 투자자는 기록 욕구가 가장 강한 세그먼트)
- 검토 항목(데이터로 결정): 증권사 CSV 거래내역 임포트(각 사 다운로드 포맷 파서 — 계좌 연동 없이 자동 입력에 근접하는 우회로), 읽기 전용 공유 링크(가족에게 보여주기)
- 유료 500명(월 매출 ~250만원) 목표

## 5. 마케팅: 광고비 없이 시작하는 순서

금융 기록 도구는 검색과 커뮤니티에서 신뢰로 크는 제품이다. 유료 광고는 Phase 3 전까지 하지 않는다.

### 5-1. SEO 콘텐츠 (가장 확실한 복리 자산)

온보딩 가이드가 그대로 검색 콘텐츠가 된다. 타깃 키워드 예:

- "주식 포트폴리오 엑셀 관리" / "구글 스프레드시트 주식 관리" — 스프레드시트 고통을 겪는 사람이 정확히 우리 타깃. "엑셀로 하는 법" 콘텐츠를 진심으로 잘 써주고 마지막에 "이걸 자동으로 하려면"으로 연결
- "미국주식 수익률 계산 환율" / "달러 주식 원화 수익률" — 우리가 실제로 잘하는 것
- "TWR MWR 차이" / "내 진짜 수익률 계산" — 교육 콘텐츠이자 차별 기능 소개 (조언 아님, 계산 방법 설명)
- "연금저축 ISA 포트폴리오 한눈에" — 타깃 2번 직격
- "증권사별 평단가 확인 방법" 시리즈 — 온보딩 문서 재활용

블로그는 본 도메인 하위(`/blog`)에 두어 도메인 권위를 모은다.

### 5-2. 커뮤니티 (초기 100명의 출처)

- **디스콰이엇, GeekNews** — 사이드 프로젝트/개발자 커뮤니티에 제작기 공유. "가족 포트폴리오를 Numbers로 관리하다 지쳐서 직접 만들었다"는 서사는 이 동네에서 잘 작동한다. 개발자는 얼리어답터이자 미국주식 투자 비율이 높다.
- **재테크 커뮤니티(각종 카페, 클리앙/뽐뿌 재테크 게시판 등)** — 홍보가 아니라 "스프레드시트 양식 무료 공유 + 이걸 웹으로 만든 게 있다" 접근. 커뮤니티 규칙 준수가 생명.
- **오픈 카톡/디스코드 사용자 모임** — 초기 100명과 직접 대화하는 채널. 기능 요청과 이탈 이유를 여기서 듣는다.

### 5-3. 콘텐츠 협업 (Phase 2)

- 재테크·미국주식 유튜버/블로거에게 **광고비가 아니라 제품으로** 접근: "구독자용 6개월 무료 코드". 단, 종목 추천 채널이 아닌 기록·절세·연금 관리 채널을 고른다 — 포지셔닝 오염 방지.
- 뉴스레터(어피티, 순살브리핑류) 도구 소개 코너 피칭.

### 5-4. 제품 자체가 하는 마케팅

- **공유 가능한 이미지**: "이번 달 내 포트폴리오 요약" 카드를 금액 숨김 모드(비율만 표시)로 이미지 저장 → SNS 공유. 금액 노출 없이 자랑 욕구만 충족시키는 게 핵심 설계.
- **JSON/XLSX 완전 내보내기를 전면에**: "언제든 떠날 수 있는 서비스"라는 역설적 신뢰 신호. 락인이 아니라 만족으로 붙잡는다는 메시지 자체가 차별화.
- 추천 코드: 친구 가입 시 양쪽 1개월 무료 — 가족 총무가 다른 가족 총무를 데려온다.

### 5-5. 측정

- 퍼널: 방문 → 가입 → 첫 종목 입력(활성화) → 7일 재방문 → 결제. 각 단계 전환율을 주간으로 본다. 활성화(첫 종목 입력)율이 최우선 지표다.
- 분석 도구는 프라이버시 친화적인 것(자체 호스팅 또는 쿠키리스)을 쓴다 — "광고·추적 없음" 포지셔닝과 일관성.

## 6. 하지 않을 수익화 (명시적 기각)

- **광고** — 신뢰 파괴, 단가도 낮다.
- **금융상품 제휴/추천 수수료** — "추천 없음" 포지셔닝의 자살. 증권사 계좌 개설 제휴도 같은 이유로 기각.
- **종목 분석·시그널·리딩 구독** — CLAUDE.md 제약 위반 + 유사투자자문업 리스크. 논외.
- **데이터 판매·통계 판매** — 익명화 여부와 무관하게 논외. 개인 금융 기록 도구의 존재 이유를 부정한다.
- **B2B(자문사용 툴) 피벗** — 시장은 있으나 규제·요구사항이 전혀 다른 제품이 된다. 개인용이 자리잡기 전에는 검토하지 않는다.

## 7. 리스크와 정직한 전망

- **시세 소스 리스크**: Yahoo 비공식 API로 유료 서비스를 돌리는 것은 약관·안정성 양면에서 취약하다. 유료 전환 시점에는 폴백(15번 축 4)과 함께, 유료 시세 API(국내: KRX 정보데이터, 해외: 상용 API) 비용을 요금제에 반영하는 계산이 필요하다. 대략 유료 200명 이후의 문제.
- **오픈뱅킹 연동 앱과의 경쟁**: "자동 연동"은 우리가 못 이긴다. 이기려 하지 말고 "연동을 원치 않는 사람, 가족 단위, 기록 소유권"의 틈새를 깊게 판다. 틈새가 작아 보여도 스프레드시트로 자산 관리하는 인구는 꾸준히 크다.
- **현실적 규모**: 이 제품의 1차 성공은 "월 구독 500명, 서버비·시세 API비 제하고 월 200만원"이다. 유니콘 스토리가 아니라 지속 가능한 개인 SaaS 스토리이며, 로드맵도 그 규모에 맞게 설계했다. 그 이상은 Phase 3의 데이터가 말해줄 것이다.
